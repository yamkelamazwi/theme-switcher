# Accessible Theme Switcher

A simple theme switcher built with HTML, CSS, and JavaScript that allows users to switch between Light and Dark themes.

## Features

- Toggle between Light and Dark themes
- Accessible dropdown menu
- Uses ARIA attributes for improved accessibility
- Live status updates using `aria-live="polite"`
- Dynamic theme switching with JavaScript
- Smooth color transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## What I Learned

While building this project, I practiced:

- DOM manipulation
- Event listeners
- Working with arrays of objects
- Adding and removing CSS classes dynamically
- Using ARIA attributes for accessibility
- Updating content dynamically with JavaScript
- Managing UI state with conditional logic
